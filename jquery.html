jQuery

Menos sintaxis para tareas comunes. La misma base: JavaScript.

JavaScript con una librería

jQuery es una librería escrita en JavaScript, no un lenguaje diferente. Surgió para facilitar tareas repetidas de selección de elementos, eventos y efectos, y resolver diferencias entre navegadores que antes exigían más código.

¿Qué significa el símbolo $?

$ es un alias de jQuery. En $("#panel") se selecciona el elemento con ese identificador. El resultado es un objeto jQuery que permite encadenar métodos como .on() y .text().

jQuery
$("#boton").on("click", function() {
  $("#mensaje").text("¡Una freskura, por favor!");
});

Primero se carga la librería y después el código que la utiliza. En este proyecto jQuery se incluye como archivo local.

Ventajas

  • Sintaxis compacta para manipular el DOM.
  • Efectos listos para utilizar.
  • Útil en proyectos existentes que dependen de ella.

Desventajas y decisiones

  • Añade una dependencia y una descarga al sitio.
  • Las APIs modernas ya resuelven muchas de esas tareas.
  • Debe mantenerse y ser compatible con los plugins usados.

Efectos en vivo

fadeIn()

Muestra gradualmente un elemento oculto.

Es de jamaica. Parece limón. Sabe a tamarindo.

slideToggle()

Alterna la apertura y el cierre con un deslizamiento.

La que parece de jamaica es de tamarindo, pero sabe a limón.

jQuery
$("#fadeBtn").on("click", function() {
  $("#fadePanel").fadeIn(400);
});
$("#slideBtn").on("click", function() {
  $("#slidePanel").slideToggle(400);
});

El número 400 indica la duración en milisegundos. Si el dispositivo solicita reducir movimiento, el sitio omite la animación.
