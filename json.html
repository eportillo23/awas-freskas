JSON

Un formato para compartir información, no para ejecutar instrucciones.

Datos que viajan como texto

JSON significa JavaScript Object Notation. Es un formato de texto para representar datos, independiente del lenguaje de programación. Su sencillez facilita el intercambio entre navegadores, servidores y APIs.

Clave y valor

"nombre": "Jamaica" asocia una clave con un valor.

Objeto

Las llaves { } agrupan propiedades relacionadas, por ejemplo los datos de una bebida.

Arreglo

Los corchetes [ ] contienen una lista ordenada, como las tres bebidas.

Admite cadenas, números, booleanos, null, objetos y arreglos. Las claves y cadenas llevan comillas dobles. No admite comentarios, funciones, undefined ni comas finales.

Objeto JavaScript y texto JSON

Objeto JavaScript
const bebida = {
  nombre: "Jamaica",
  parece: "Limón",
  sabe: "Tamarindo"
};
Texto JSON
{
  "nombre": "Jamaica",
  "parece": "Limón",
  "sabe": "Tamarindo"
}

El objeto existe en memoria; JSON es su representación textual. JSON.stringify() convierte a texto y JSON.parse() interpreta el texto para recuperar los datos.

JavaScript
const texto = JSON.stringify(bebida);
const objeto = JSON.parse(texto);
console.log(objeto.nombre);

Del servidor a la página

Una aplicación envía una petición HTTP. La respuesta puede contener JSON; el navegador interpreta esos datos y los muestra. El catálogo de este sitio es un archivo estático, no una API con base de datos.

JavaScript
async function cargarBebidas() {
  const respuesta = await fetch("assets/bebidas.json");
  if (!respuesta.ok) throw new Error("No se pudo cargar");
  const bebidas = await respuesta.json();
  return bebidas;
}
