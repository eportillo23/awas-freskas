JavaScript

HTML presenta, CSS viste y JavaScript hace que las cosas pasen.

El comportamiento de la web

JavaScript es un lenguaje de programación. En el navegador permite responder a acciones, actualizar contenido y trabajar con datos. “Vanilla” significa utilizar JavaScript directamente, sin una librería como jQuery.

HTML

Estructura

Define títulos, párrafos, imágenes y botones. Es el contenido organizado.

CSS

Estilo

Define colores, tamaños y distribución. Da forma visual a la marca.

JS

Comportamiento

Decide qué ocurre al pulsar un botón, cambiar una opción o enviar un formulario.

Variables, funciones y eventos

Variables

let permite reasignar un valor. const evita reasignar la referencia, aunque un objeto o arreglo puede modificarse. var tiene alcance de función y aparece con frecuencia en código antiguo.

Funciones

Agrupan instrucciones reutilizables. Pueden recibir parámetros y devolver resultados. Definir una función no la ejecuta: hay que llamarla.

Eventos

click detecta una activación; change, un cambio. Para pasar el puntero se puede usar mouseenter. “Hover” describe la interacción; no es el nombre de un evento nativo. En CSS existe :hover.

Prueba: cambia el sabor

Un botón recorre un arreglo. HTML contiene el resultado; JavaScript modifica su texto.

RESULTADO EN VIVO

Jamaica

JavaScript
const sabores = ["Jamaica", "Limón", "Tamarindo"];
let indice = 0;
function cambiarSabor() {
  indice = (indice + 1) % sabores.length;
  document.querySelector("#saborDemo").textContent = sabores[indice];
}
document.querySelector("#cambiar").addEventListener("click", cambiarSabor);
  1. sabores guarda los tres nombres; indice señala el elemento actual.
  2. La función suma uno. El operador % hace que el índice vuelva a cero después del último sabor.
  3. querySelector encuentra un elemento; textContent cambia su texto.
  4. addEventListener conecta el evento click con la función.

Para investigar

¿Qué pasaría si quitaras % sabores.length? ¿Cómo cambiarías la función para avanzar dos sabores por clic?
